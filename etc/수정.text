다시한번 아래 내용을 보고 최종 수정을 해서 index.html과 admin.html 파일을 webapp에 만들어줘.
sql의 경우 헷갈리지 않게 뒤에 버전을 붙여줘.

달력 스케줄 클릭 시 상담 미출석 -> 수업과 동일한 이벤트 발생
달력: 미출석, 수업완료, 상담완료건 클릭 시 모달창 상세보기(내담자 -> 수업이력, 예약상담자->상담이력), 삭제(삭제 시 캘린더에서만 삭제, 실제 수업이력, 상담이력은 삭제 안됨.)
상담 예약자 -> 내담자로 변경 시 기존 상담이력은 수업이력에 그대로 노출

캘린더 위 일정 카드 선택  시 빈화면만 나오는 이슈 발생

주간, 일간 선택 시 현재 시간 기준으로 자동 스크롤

수업진행 중 GNB 영역에 타임 시간 시작.

관리자 페이지에서 등록된 선생님 비밀번호가 그대로 노출되고 있어. ****로 노출
관리자가 선생님 비번 변경 시 관리자 비번 입력 후 선생님 비번 변경 가능하게 해줘, 이때 비번은 2번 입력해서 최종 변경
