# Play Lab 콘텐츠

이 폴더에는 HAHA LAB의 Play Lab 학습 콘텐츠가 포함되어 있습니다.

## 📚 콘텐츠 목록

### 생각 플레이 (인지학습)

#### 01-000.html - 색깔 맞추기
- **난이도**: ⭐⭐
- **목표**: 시지각 인지 능력, 색상 변별력 향상
- **설명**: 제시된 색상과 동일한 색상을 선택하는 게임
- **태그**: `#색깔인지` `#시지각` `#주의집중`

#### 01-001.html - 신호등 지킴이
- **난이도**: ⭐⭐
- **목표**: 규칙 이해력, 반응 억제 능력 향상
- **설명**: 신호등 색깔에 맞춰 올바른 행동을 선택하는 게임
- **태그**: `#규칙학습` `#억제조절` `#안전교육`

#### 01-002.html - 시공간 두더지 잡기
- **난이도**: ⭐⭐⭐
- **목표**: 시공간 인지, 빠른 반응 속도, 주의 집중력
- **설명**: 나타나는 두더지를 빠르게 터치하는 게임
- **태그**: `#반응속도` `#시공간인지` `#협응력`

## 🎮 사용 방법

### 1. 로컬에서 실행
```bash
# 단일 파일 실행
open 01-000.html
# 또는
python3 -m http.server 8000
```

### 2. 웹 서버에 배포
- 각 HTML 파일은 독립적으로 실행 가능합니다.
- CDN 방식으로 라이브러리를 로드하므로 별도 설치 불필요

### 3. HAHA LAB 시스템에 등록

관리자 페이지에서 콘텐츠 등록:
```javascript
{
  catId: 'think',
  title: '색깔 맞추기',
  url: '/playlab/01-000.html',
  tags: ['색깔인지', '시지각', '주의집중'],
  thumbnail: 'thumbnail_url'
}
```

## 🛠️ 기술 스택

- **프론트엔드**: HTML5, CSS3, Vanilla JavaScript
- **스타일링**: Tailwind CSS
- **차트**: Chart.js
- **아이콘**: Material Symbols
- **폰트**: 
  - Jua (게임 UI)
  - Noto Sans KR (본문)
  - HappinessSansTitle (제목)

## 📱 반응형 지원

- 모바일, 태블릿, 데스크톱 모두 지원
- 터치 및 마우스 입력 모두 가능
- `user-scalable=no`로 확대/축소 방지

## 📊 결과 분석

각 게임은 다음 데이터를 제공합니다:
- **정확도**: 정답률 (%)
