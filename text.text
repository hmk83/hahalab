관리자 페이지
1. 공지사항 수정 및 삭제, 숨기기 기능 추가

사용자 페이지
1. 삭제된 프로필의 경우 스케줄 클릭 시 삭제된 내담자 또는 예약 상담자입니다. 삭제 버튼만 노출
2. 내담자, 예약 상담자 프로필 삭제할 경우 기존에 완료하지 않은 상담, 수업은 일괄 삭제 처리
3. 수업종료, 상담종료, 일정변경, 미출석, 삭제에 대한 내역들은 모두 프로필 내 수업이력 및 상담이력에 기록
수업시작 언제해서 언제 종료 총 몇분
상담 시작 언제 언제 종료 총 몇분
수업 원래 날짜 변경날짜
상담 원래 날짜 변경날짜
수업 미출석 날짜 시간
예약 미출석 날짜 시간
어떤 내역이 언제 삭제되었다.


상담예약자 -> 수업이력 -> 상담예약
상담예약자가 내담자로 변경 시 상담예약 -> 수업이력으로 변경, 기존 상담예약 내역은 수업이력에 남겨두면됨

해당 내용을 해서 SQL까지 완성본으로 만들어줘.
